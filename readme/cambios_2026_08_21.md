# Cambios del 21 de Agosto de 2026

## Backend
1. **Debug Preprocesamiento (Auto-Fusión)**:
   - Se modificó `_find_similar_items` en `preprocessing_service.py` para extraer directamente los objetos `CostItem` del resultado de búsqueda híbrida, y se añadió la devolución de la traza completa de candidatos con sus scores (`scored_items`).
   - Se actualizó `preprocess_apu_data` en `preprocessing_service.py` para inyectar `auto_fusion_trace` dentro del payload de respuesta del servidor (incluyendo la ganadora, complementarias y top 40). Esto arregla el problema donde el panel de "Debug de Preprocesamiento" mostraba "No disponible" o estaba vacío al usar el modo Auto-Fusión.

## Frontend
1. **Asistente IA (Chatbot)**:
   - Se arregló un bug crítico (`TypeError: P.id.includes is not a function`) que ocurría porque el ID del mensaje inicial era un número en lugar de un string.
   - Se personalizó el saludo inicial para usar el nombre del usuario inyectado (Ej: "¡Hola CostBase!").
   - Se modificó el texto del primer mensaje a: *"En 4 pasos rápidos armaremos la mejor descripcion basándonos en la información suministrada."*
   - Se ajustó el ancho del modal de interacción del chatbot para que sea más angosto y parecido a un bot tradicional (cambio de `max-w-2xl` a `max-w-lg`).
   - Se arreglaron las burbujas de respuesta del usuario para que el texto fluya naturalmente en una sola fila cuando es corto, eliminando anchos forzados (`w-fit`) y saltos de línea artificiales (`break-words`), sustituyéndolo por `inline-block` y `whitespace-pre-wrap`.

2. **Barra Lateral (Sidebar)**:
   - Se eliminó el scroll doble (barras de desplazamiento innecesarias) quitando las propiedades `overflow-y-auto` que causaban conflictos de recorte (clipping).
   - El arreglo del overflow también resolvió el problema de los tooltips (nombres de los iconos al hacer hover) que estaban invisibles/recortados.
   - Se aplicó el color `#FEF3C7` para el efecto `hover` en los iconos de navegación para resaltar la selección activa visualmente.

## Base de Datos
- Se actualizó el nombre (full_name) del administrador `admin@arko360.net` a `CostBase` en las tablas `ArkoAdmin` y `ArkoUser`.
